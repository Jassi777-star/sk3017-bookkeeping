# Debug 日志

## BUG-001｜2026-10-28｜近 6 个月统计接口返回 400

- **现象**：调用 `/api/statistics/months?end=2026-10&count=6` 时返回 400，提示月份格式错误。
- **根因**：接口实现沿用了分类统计的 `month` 参数，但契约规定该接口使用 `end`，因此没有读到有效月份。
- **解决**：将月份解析提取为带参数名的函数，近 6 个月接口显式读取 `end`；前端请求同步改用 `end`。
- **预防**：为每个 JSON 接口保留契约级测试，参数名变更必须同时修改测试、后端和前端。

## BUG-002｜2026-10-28｜seed-demo 命令 TypeError

- **现象**：执行 `flask seed-demo` 时抛出 `TypeError: unsupported operand type(s) for /: 'str' and 'int'`。
- **根因**：构造演示金额时先把随机整数转成字符串，再执行除法，类型顺序写反。
- **解决**：先以整数除法生成 Decimal，再把结果写入 `DECIMAL(12,2)` 字段。
- **预防**：新增演示数据生成测试，验证首次生成成功、金额可写入且重复执行不会重复灌入。

## BUG-003｜2026-10-29｜移动端饼图标签截断

- **现象**：在 390px 宽度下，分类占比饼图的外置标签显示不完整，百分比和分类名被省略。
- **根因**：桌面端沿用的外置标签在窄图表中需要占用两侧额外空间，图例和外置标签同时存在时空间不足。
- **解决**：窄屏隐藏外置标签和引导线，保留底部图例和悬浮提示；窗口尺寸变化时使用缓存数据重新渲染。
- **预防**：每次界面改动都在桌面端和移动端分别截图验证，并检查页面横向溢出和图表绘制像素。
